# Anime Pricing Page

My first Front-End Development project, built with **HTML5** and **CSS3** as part of my self-learning journey.

A fictional anime streaming subscription page created to practice webpage structure, styling and visual design.

---

## Technologies

- HTML5
- CSS3

## What I Learned

- Structuring webpages with HTML
- Styling elements with CSS
- Working with typography and color palettes
- Creating subscription plan cards
- Organizing webpage sections and layouts
